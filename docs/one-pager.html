The problem

Industrial inspection is still a clipboard. The failure mode isn't carelessness — it's that nobody can answer "has this actually changed since March?" without standing in the same spot, in the same light, with the same memory. The hard part was never detecting rust; it is change over time under uncontrolled capture conditions. And when a system can't tell, it should stop and ask a human rather than guess — which is why ours does.

How one upload becomes a work order

01
Quality gate
Blur as variance of the Laplacian, plus exposure, glare, coverage. Below threshold → pause.
02
Registration
ORB + findHomography(RANSAC), scored on measured inlier ratio and reprojection error, warped with a validity mask.
03
Change detection
absdiff → threshold → morphology → contours, cross-checked against SSIM. Regions get relative bboxes.
04
Evidence → ticket
Six artifacts per finding, a finding with measured severity, and a priority-ranked maintenance ticket.

The planner is a deterministic bounded state machine — a transition table over states with three hard limits (iterations, wall-clock, repeat guard). planner: "deterministic-rule-v1" is recorded on every run. No language model is involved, and the app publishes that itself.

The same run "contradicting" its own headline was this: a looser τ accepts sloppier boxes, so recall rises while precision and mean IoU of survivors fall. The UI labels the threshold and seed on screen — a metric without them is unattributable.

What we fixed, and what we refuse to claim

  • Our test fixture used warpAffine(BORDER_REPLICATE), which manufactured an edge band the detector reported as whole-frame defects at 0.96 confidence on clean captures. Found only by running 18 captures back to back — no unit test reached it.
  • Alignment never wrote its validity mask, so the warp border scored as change. Fixed: 36 clean pairs now produce 0 false regions.
  • Correcting both lowered the headline score (0.90/1.00 → 0.886/0.689). That was the honest direction.
  • No AWS, S3 or COOL integration. Runs on a Raspberry Pi 5. GET /api/system/capabilities publishes this — we shipped the endpoint that can refute us.
  • Benchmark metrics describe a synthetic corpus, not real plant imagery.
  • Video is frame sampling with measured sharpest-frame selection — no per-frame defect tracking, no live camera.
