Deterministic bounded planner — not a language model
A transition table over states, choosing the next action from the measurement the last stage returned. Three hard limits stop it: iteration count, wall-clock budget, and a repeat guard. planner: "deterministic-rule-v1" is recorded on every run.
Human-in-the-loop — the run stops and asks
A failed quality gate or a registration that measures a near-zero inlier ratio pauses the run, serialises its context to JSON, and resumes from that snapshot when a human answers. It does not restart, and it does not guess.
